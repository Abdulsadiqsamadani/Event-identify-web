# 📖 UDUS Tech Summit Website <a name="about-project"></a>

**UDUS Tech Summit Website** is a responsive website built to showcase the **UDUS Tech & Knowledge Summit 2026**.

The website highlights the event details, program schedule, speakers, and partners involved in the summit. It is designed to provide a clean and modern user interface for visitors interested in the event.

To run this project you need:

```
Web browser (Chrome, Firefox, Edge)
Git
```

Clone the repository:

```

```

Go into the project folder:

```
cd your-repository-name
```

Open the project in your browser:
